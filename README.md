# 我的替身 · 玻璃方格

一个上班时可以打开的网页小玩具：玻璃方格里的小人就是你自己。现实里的你只能老老实实上班，但你可以让他替你去做那些不敢做的事。

## 两个版本

| 文件 | 内容 |
|---|---|
| [`solo.html`](solo.html) | **一个人的方格**：只有你和你的工位 |
| [`office.html`](office.html) | **同事的方格**：开放式办公室，加上六个有性格的同事 |
| [`sneak.html`](sneak.html) | **摸鱼潜行**（试玩版）：第一人称潜行玩法，一周五天 |
| [`index.html`](index.html) | 入口页，可以选择打开哪一个 |

## 怎么玩

- **设定自己**：第一次打开时填名字、职位、老板怎么称呼、下班时间、月薪（选填），再选穿着、发型、发色、肤色和衣服颜色。
- **下命令**：在底部打字（例如“我想当面怼老板”“去海边”“睡一觉”），或者点“发泄 / 偷懒 / 逃离”分类里的按钮。
- **发泄**：怼老板、掀桌子、摔键盘、撕周报、大喊。
- **偷懒**：躺沙发睡、趴桌睡、刷手机、看剧、打游戏、发呆、跳舞。
- **逃离**：辞职、准点下班、请假去海边。
- **直接互动**：点一下小人是摸头，按住拖动能把他拎起来；丢到沙发、街机、饮水机或门口，他就去做对应的事。
- **替身日记**：记下他今天替你做了哪些事，而现实的你一件都没做。
- **压力、下班倒计时、带薪摸鱼收入**都显示在左上角。
- **切换视角**：右上角视角按钮或按 `V`，在 🎥 全景 / 🎯 跟随 / 🧍 背后 / 👀 第一人称 之间切换。第一人称就是从替身的眼睛看出去：低头打字、躺沙发看天花板都会跟着动；拖动屏幕转头，双击回正，他说的话会变成屏幕下方的字幕。他离开方格（下班、辞职、去海边）时会自动退回全景，回来后接上。
- **老板键**：按 `Esc`，整个页面一秒变成一张 Excel 周报，再按一次回来。

## 同事版多了什么

- 六个同事：卷王、摸鱼搭子、八卦王、马屁精、实习生、佛系。各自有平时的小动作。
- 他们会对替身做的事起反应：怼老板时有人录像有人鼓掌，下班时摸鱼搭子跟着走，摸鱼时卷王可能去告状把老板叫来。
- 点任何一个同事，可以让替身走过去翻白眼、送咖啡、做鬼脸或聊天；也可以直接打字，例如“给小王翻个白眼”。
- 右上角“👥 同事”可以照着你现实里的同事改名字、性格、穿着、发型和衣服颜色。

## 摸鱼潜行（试玩版）

第一人称，撑过周一到周五。

- **一天大约 3 分钟**（游戏里 9:00–18:00）。坐在工位上工作会涨 KPI（每天要到 60），但压力也会涨，压力满了会当众崩溃。
- **摸鱼清单**：每天 3–4 件，比如在沙发上睡一觉、打一局街机、带薪上厕所、偷坐老板椅。走到地方**按住 E** 完成，能解压。
- **老板**：地上的红色扇形是他的视野。被他看到正在摸鱼会被抓（扣好感、扣 KPI、被拎回工位）；在外面晃久了他也会起疑。他会巡逻、回办公室、去开会，走路有脚步声，越近越响。
- **掩护**：书架、隔墙挡视线；**蹲下**（C）可以躲在桌子后面；厕所里谁也看不到。跑步（Shift）有声音，老板会回头。
- **同事**：卷王时不时回头，看到你摸鱼会去告状；摸鱼搭子在老板靠近时咳嗽提醒；八卦王看到了会传出去（当天结算扣好感）；马屁精见到老板就拍马屁。
- **一周的变化**：周一老板特别警觉；周三下午开周会；周四老板心情差，罚得更狠；周五老板四点就走。
- **结局**：根据一周的摸鱼次数、被抓次数、KPI 和老板好感，走向摸鱼宗师、升职、平衡大师、裸辞、被裁员等不同结局。
- **操作**：WASD 走路、鼠标看（点一下画面锁定鼠标）、Shift 跑、C 蹲、E 互动、V 全景（看清局势，但这段时间你在发呆，不涨 KPI）、Esc 老板键。手机上是左下摇杆、右边拖动转头、E 和蹲两个按钮。
- 会沿用你在“我的替身”里设定的样子、老板称呼和同事设定；一周进度单独保存。

## 怎么打开

- 直接双击 HTML 文件，用浏览器打开即可。
- 需要联网：3D 引擎 [three.js](https://threejs.org/) 从 CDN 加载。
- 所有记录（名字、日记、同事设定）只保存在你自己浏览器的 localStorage 里，不会上传。

## 技术说明

- 单个 HTML 文件，无需构建，无外部模型文件；人物和场景都用代码生成。
- 人物比例和低多边形画风参考了 [Quaternius](https://quaternius.com/) 的 CC0 人物，但没有使用其模型文件。
